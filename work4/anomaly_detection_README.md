# 任务二：异常数据发现说明

## 目标

本部分面向作业四导出的 `student`、`course`、`sc` 三张表，完成异常数据发现与可复核结果导出。脚本使用 Python 标准库实现，不依赖额外第三方包。

## 运行方式

在项目根目录执行：

```bash
python3 work4/anomaly_detection.py
```

脚本读取：

- `work4/hw4_20260614/student.csv`
- `work4/hw4_20260614/course.csv`
- `work4/hw4_20260614/sc.csv`

脚本输出：

- `work4/task2_anomaly_report.html`：异常检测 HTML 报告，适合直接打开查看和截图。
- `work4/anomaly_summary.csv`：按表、规则、组号、院系聚合后的异常汇总。
- `work4/anomaly_records.csv`：异常明细记录，便于定位具体学生、课程或选课记录。
- `work4/score_quality_profile.csv`：按组号和院系统计成绩有效性、缺失、低分、均分和及格率。

## 检测规则

1. **关键字段完整性**：检查 `student_id`、`course_id`、`group_no`、`dept_no` 等关键字段是否为空、`NUL`、`NULL` 或其他缺失占位。
2. **字段取值范围**：检查组号是否为数字、院系是否属于 `A/B/C`，成绩是否在 `0-100` 之间。
3. **业务主键重复**：检查同一组、同一院系内学生、课程和选课业务主键是否重复。
4. **选课引用一致性**：检查 `sc` 表中的学生和课程能否在对应 `student`、`course` 表中找到。
5. **提交规模偏差**：按作业标准检查每组数据量是否接近 `student=150`、`course=30`、`sc=750`，以及每个院系是否接近 `50/10/250`。
6. **成绩质量画像**：统计成绩缺失、非法成绩、低分/不及格、均分、标准差和及格率。

## 异常等级说明

- `ERROR`：会影响后续统计或表间关联的严重问题，例如成绩缺失、课程不存在、学生不存在、成绩越界。
- `WARNING`：字段写法或规模分布可疑，例如学时缺失、共享标记不规范、提交数量偏离标准。
- `INFO`：不一定是数据错误，但可作为后续分析关注点，例如低分/不及格记录。
