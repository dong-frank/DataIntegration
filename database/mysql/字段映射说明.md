# 学院 C MySQL 字段映射说明

> 底层表严格依据 PDF《基于 XML 数据集成的集成教务系统示例》表 3-11、表 3-12 的命名风格设计；
> 在底表之上提供适配器视图 `vw_adapter_students` / `vw_adapter_courses` / `vw_adapter_enrollments`，
> 由后端通过视图统一读取，从而保留底层表的异构性，又满足上层接入的统一字段需求。

## 1. 底层表 (PDF 风格，异构原貌)

### 1.1 学生表 `C_STUDENT` (对应 PDF 表 3-11)

| 字段  | 类型         | 约束        | 说明     |
|-------|--------------|-------------|----------|
| Sno   | VARCHAR(9)   | PRIMARY KEY | 学号     |
| Snm   | VARCHAR(10)  |             | 姓名     |
| Sex   | VARCHAR(1)   |             | 性别     |
| Sde   | VARCHAR(6)   |             | 院系     |
| Pwd   | CHAR(6)      |             | 密码     |

### 1.2 课程表 `C_COURSE` (对应 PDF 表 3-12)

| 字段  | 类型         | 约束        | 说明      |
|-------|--------------|-------------|-----------|
| Cno   | CHAR(4)      | PRIMARY KEY | 课程编号  |
| Cnm   | VARCHAR(10)  |             | 课程名称  |
| Ctm   | INTEGER      |             | 课时      |
| Cpt   | INTEGER      |             | 学分      |
| Tec   | VARCHAR(20)  |             | 授课老师  |
| Pla   | VARCHAR(18)  |             | 授课地点  |
| Share | CHAR(1)      | Y/N         | 共享标记  |

> 课时 `Ctm` 与授课地点 `Pla` 是统一课程 XML 与课程共享流程必需字段，已按 PDF 要求补齐。

### 1.3 选课表 `C_SELECTION` (对应 PDF 表 3-11 选课部分)

| 字段 | 类型      | 约束                        | 说明     |
|------|-----------|-----------------------------|----------|
| Cno  | CHAR(4)   | FOREIGN KEY → C_COURSE.Cno  | 课程编号 |
| Sno  | CHAR(9)   | FOREIGN KEY → C_STUDENT.Sno | 学号     |
| Grd  | INTEGER   |                             | 成绩     |

> 选课表使用 `Grd` 表示成绩，不再放置 `status`。

### 1.4 跨院导入扩展表

为满足“外院学生选 C 课程后，C 服务器写入学生信息和选课信息”的流程，
在 PDF 原始三张业务表之外增加两张扩展表：

| 表名 | 说明 |
|------|------|
| `C_IMPORTED_STUDENT` | 保存外院学生在 C 服务器侧的导入快照 |
| `C_IMPORTED_SELECTION` | 保存外院学生选择 C 课程的选课记录 |

这两张表不改变 PDF 原表结构，适配视图会把本院选课和跨院选课统一输出。

## 2. 适配器视图 (供后端统一读取)

### 2.1 `vw_adapter_students`

| 视图字段 | 来源底层字段          | Java (`StudentRecord`) | 说明           |
|----------|-----------------------|------------------------|----------------|
| id       | `C_STUDENT.Sno`       | id                     | 学号           |
| college  | 常量 `'C'`            | college                | 学院代码       |
| name     | `C_STUDENT.Snm`       | name                   | 姓名           |
| gender   | `C_STUDENT.Sex`       | gender                 | 性别           |
| major    | `C_STUDENT.Sde`       | major                  | 院系/专业       |
| grade    | `LEFT(Sno,4)`         | grade                  | 入学年份(由学号前4位推导) |

### 2.2 `vw_adapter_courses`

| 视图字段     | 来源底层字段              | Java (`CourseRecord`) | 说明           |
|--------------|---------------------------|-----------------------|----------------|
| id           | `C_COURSE.Cno`            | id                    | 课程编号       |
| college      | 常量 `'C'`                | college               | 学院代码       |
| name         | `C_COURSE.Cnm`            | name                  | 课程名称       |
| hours        | `C_COURSE.Ctm`            | hours                 | 课时           |
| credits      | `C_COURSE.Cpt`            | credits               | 学分           |
| teacher      | `C_COURSE.Tec`            | teacher               | 授课老师       |
| location     | `C_COURSE.Pla`            | location              | 授课地点       |
| shared       | `Share = 'Y'` 转 1/0      | shared                | 是否共享       |

### 2.3 `vw_adapter_enrollments`

| 视图字段       | 来源底层字段                   | Java (`EnrollmentRecord`) | 说明           |
|----------------|--------------------------------|---------------------------|----------------|
| id             | `CONCAT(Cno,'-',Sno)`          | id                        | 选课记录ID     |
| studentCollege | 常量 `'C'`                     | studentCollege            | 学生所在学院   |
| studentId      | `C_SELECTION.Sno`              | studentId                 | 学号           |
| courseCollege  | 常量 `'C'`                     | courseCollege             | 课程所属学院   |
| courseId       | `C_SELECTION.Cno`              | courseId                  | 课程编号       |
| enrolledAt     | 由 `Cno` 序号推导的日期        | enrolledAt                | 选课日期       |
| status         | 常量 `'ACTIVE'`                | status                    | 选课状态       |
| score          | `C_SELECTION.Grd`              | score                     | 成绩           |

## 3. 字段映射汇总 (对应 PDF 表 3-17/3-18/3-19)

| 统一格式 XML 元素 | C 系统 XML 元素 | C 数据库底层字段 |
|-------------------|-----------------|------------------|
| id (学生)         | Sno             | `C_STUDENT.Sno`  |
| name (学生)       | Snm             | `C_STUDENT.Snm`  |
| sex               | Sex             | `C_STUDENT.Sex`  |
| major             | Sde             | `C_STUDENT.Sde`  |
| id (课程)         | Cno             | `C_COURSE.Cno`   |
| name (课程)       | Cnm             | `C_COURSE.Cnm`   |
| score / credits   | Cpt             | `C_COURSE.Cpt`   |
| teacher           | Tec             | `C_COURSE.Tec`   |
| location          | Pla             | `C_COURSE.Pla`   |
| time / 课时       | Ctm             | `C_COURSE.Ctm`   |
| sid               | Sno             | `C_SELECTION.Sno`|
| cid               | Cno             | `C_SELECTION.Cno`|
| score (成绩)      | Grd             | `C_SELECTION.Grd`|

简化映射口径：`id -> Sno/Cno`，`name -> Snm/Cnm`，`score / credits -> Grd / Cpt`，`teacher -> Tec`，`location -> Pla`。

## 4. 数据库连接信息

- 数据库名：`college_c`
- 字符集：utf8mb4
- JDBC URL：`jdbc:mysql://localhost:3306/college_c?useUnicode=true&characterEncoding=utf8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai`
- 后端读取入口：统一访问 `vw_adapter_students` / `vw_adapter_courses` / `vw_adapter_enrollments` 三张视图，底层表保持 PDF 异构原貌。
