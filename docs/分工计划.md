# 第一阶段 6 人分工计划

## 总目标

完成 React + Spring Boot 单仓库框架，跑通登录、学院端 GUI、集成服务器 GUI、统计可视化、XML 示例导出、三库配置模板和报告流程图草稿。

## 成员分工

| 成员 | 角色 | 负责内容 | 第一阶段交付物 |
| --- | --- | --- | --- |
| 成员 1 | 项目负责人 / 后端框架 | Spring Boot 项目、统一 API、登录接口、模块边界、合并检查 | `backend/` 可启动；`/api/health`、登录、学院数据、统计接口可用 |
| 成员 2 | 学院 A / SQL Server | 学院 A 表结构、初始化数据、A 适配器准备 | `database/sqlserver/init.sql`；A 学院字段映射说明 |
| 成员 3 | 学院 B / Oracle | 学院 B 表结构、初始化数据、B 适配器准备 | `database/oracle/init.sql`；B 学院字段映射说明 |
| 成员 4 | 学院 C / MySQL | 学院 C 表结构、初始化数据、C 适配器准备 | `database/mysql/init.sql`；C 学院字段映射说明 |
| 成员 5 | 前端 / React GUI | 登录页、学院端、集成服务器、统计可视化 | `frontend/` 页面可运行并能调用后端 API |
| 成员 6 | XML / 报告 / 测试 | XML/XSD、流程图、报告结构、验收清单 | `academic-integration.xsd`；`docs/流程图草稿.md`；演示步骤 |

## 推荐协作顺序

1. 成员 1 和成员 5 先保持接口字段同步，确保前后端可以联调。
2. 成员 6 基于当前接口整理报告流程图和 XML 结构。
3. 成员 2、3、4 等课本表结构到位后补真实建表和种子数据。
4. 最后由成员 1 把 Mock 数据服务替换为三院数据库适配器，由成员 5 做页面微调。
