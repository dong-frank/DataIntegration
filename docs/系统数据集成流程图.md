# 系统数据集成相关功能流程图

本文档汇总报告中可直接使用的流程图。Markdown 查看器支持 Mermaid 时可直接渲染，也可以将代码块复制到 Mermaid Live Editor、Typora、Obsidian 或 draw.io 中导出图片。

## 图 1：系统总体数据集成架构

```mermaid
flowchart LR
    A["学院 A<br/>SQL Server"] --> A1["A 学院适配器"]
    B["学院 B<br/>Oracle"] --> B1["B 学院适配器"]
    C["学院 C<br/>MySQL"] --> C1["C 学院适配器"]

    A1 --> R["统一数据服务<br/>AcademicDataService"]
    B1 --> R
    C1 --> R

    R --> X["XML 服务层"]
    X --> XSD["XSD 校验"]
    X --> XSLT["XSLT 转换"]
    XSD --> API["集成 REST API"]
    XSLT --> API
    API --> UI["React GUI<br/>学院端 / 集成端 / 统计端"]
```

## 图 2：XML 导出流程

```mermaid
flowchart TD
    A["请求导出 XML<br/>/api/xml/{college}/{type}"] --> B["识别学院和数据类型"]
    B --> C["读取学院数据"]
    C --> D["映射统一 XML 文档对象"]
    D --> E["序列化为 XML"]
    E --> F{"XSD 校验是否通过"}
    F -- "通过" --> G["返回 XML"]
    F -- "不通过" --> H["返回错误信息"]
```

## 图 3：课程共享流程

```mermaid
sequenceDiagram
    participant Admin as "集成管理员"
    participant UI as "前端集成页面"
    participant API as "集成接口"
    participant DS as "学院数据服务"
    participant XML as "XML 课程共享服务"
    participant XSD as "XSD 校验"
    participant XSLT as "XSLT 转换"

    Admin->>UI: "选择源学院和目标学院"
    UI->>API: "请求共享课程 XML"
    API->>XML: "生成目标学院课程 XML"
    XML->>DS: "读取源学院 shared=true 课程"
    DS-->>XML: "返回共享课程"
    XML->>XSD: "校验统一 classes XML"
    XML->>XSLT: "转换为目标学院 class XML"
    XML->>XSD: "校验目标学院本地 XML"
    XML-->>API: "返回转换后的 XML"
    API-->>UI: "展示共享课程结果"
```

## 图 4：跨学院选课流程

```mermaid
flowchart TD
    A["选择学生和共享课程"] --> B["生成 enrollmentRequests XML"]
    B --> C["提交 XML 选课接口"]
    C --> D["统一 XSD 校验"]
    D --> E{"校验通过"}
    E -- "否" --> F["返回校验错误"]
    E -- "是" --> G["解析选课四元组"]
    G --> H["根据课程学院定位目标学院"]
    H --> I{"学生是否来自外院"}
    I -- "否" --> J["写入本院选课表"]
    I -- "是" --> K["读取源学院学生信息"]
    K --> L["写入目标学院外院学生表"]
    L --> M["写入目标学院导入选课表"]
    J --> N["返回选课记录"]
    M --> N
    N --> O["刷新页面和统计数据"]
```

## 图 5：集成退课流程

```mermaid
flowchart TD
    A["选择选课记录"] --> B["生成 withdrawRequests XML"]
    B --> C["提交 XML 退课接口"]
    C --> D["统一 XSD 校验"]
    D --> E{"校验通过"}
    E -- "否" --> F["返回校验错误"]
    E -- "是" --> G["解析 enrollmentId"]
    G --> H["依次调用 A/B/C 学院退选服务"]
    H --> I{"是否找到记录"}
    I -- "是" --> J["更新或删除目标学院选课记录"]
    I -- "否" --> K["返回未找到"]
    J --> L["返回退课成功"]
    K --> M["返回退课失败"]
    L --> N["刷新学院端和统计页"]
    M --> N
```

## 图 6：全局统计流程

```mermaid
flowchart TD
    A["打开统计可视化页面"] --> B["GET /api/integration/stats"]
    B --> C["读取 A/B/C 学生数据"]
    B --> D["读取 A/B/C 课程数据"]
    B --> E["读取 A/B/C 选课数据"]
    C --> F["统计学生总数和各学院学生数"]
    D --> G["统计课程总数并按课程名分组"]
    E --> H["统计选课总数和各学院选课数"]
    G --> I["识别重叠课程"]
    F --> J["组装 StatsSummary"]
    H --> J
    I --> J
    J --> K["前端指标卡、柱状图和列表展示"]
```

## 图 7：数据集成异常处理流程

```mermaid
flowchart TD
    A["收到 XML 或业务请求"] --> B["参数检查"]
    B --> C{"参数是否合法"}
    C -- "否" --> D["返回 400 参数错误"]
    C -- "是" --> E["执行 XSD 校验"]
    E --> F{"XML 是否符合契约"}
    F -- "否" --> G["返回 400 XML 校验错误"]
    F -- "是" --> H["执行 XSLT 转换或业务写入"]
    H --> I{"处理是否成功"}
    I -- "是" --> J["返回 success=true"]
    I -- "否" --> K["返回失败原因并保留原始数据"]
```
